========================================================
  الوكيل — نظام إدارة حضور العمال
  دليل التشغيل على جهازك (Windows)
========================================================

هذه الحزمة تشغّل النظام كاملًا على جهازك: البرنامج + قاعدة البيانات.
لا تحتاج تثبيت أي شيء برمجي، فقط البرنامجين المجانيين في "المتطلبات".


----------------------
المتطلبات (مرة واحدة)
----------------------
1) ويندوز 10 أو 11 (64-bit).
2) Docker Desktop  —  https://www.docker.com/products/docker-desktop/
alwakeelapp 
3) Tailscale       —  https://tailscale.com/download/windows
4) اتصال بالإنترنت (أول تشغيل فقط، لتنزيل البرنامج).


--------------------------
قبل أول تشغيل (مرة واحدة)
--------------------------
1) ثبّت Docker Desktop ثم شغّله، وانتظر حتى تظهر الأيقونة
   بحالة "Running" (دقيقة تقريبًا).

2) ثبّت Tailscale وسجّل الدخول بنفس الحساب/الشبكة التي دُعيت إليها.
   (اسألنا إذا لم تصلك دعوة الشبكة.)

3) انسخ هذا المجلد إلى مكان بسيط بدون مسافات، مثل:

        C:\alwakeel


--------------
التشغيل
--------------
• اضغط دبل كليك على الملف:   START.bat

• أول تشغيل يأخذ بضع دقائق (تنزيل البرنامج). اترك نافذة سوداء
  تعمل حتى تظهر لك رسالة خضراء فيها رابط يبدأ بـ https://

• افتح ذلك الرابط من أي متصفح (على الجهاز أو أي جهاز/جوال
  في نفس الشبكة):

        https://اسم-الجهاز.شبكتك.ts.net


------------------
تسجيل الدخول
------------------
اسم المستخدم (أو البريد) وكلمة المرور مكتوبان في ملف ".env"
الموجود بجانب الملفات. يُنصح بتغيير كلمة المرور من صفحة
"المستخدمين" بعد أول دخول.


------------------
الإيقاف والتشغيل
------------------
• للإيقاف: اضغط دبل كليك على:  STOP.bat
  بياناتك محفوظة ولا تُفقد.

• لتشغيله مرة أخرى:  START.bat  (يفتح بسرعة هذه المرة).


------------------
النسخ الاحتياطي
------------------
لعمل نسخة احتياطية من كل البيانات، افتح PowerShell في هذا
المجلد ونفّذ:

    docker compose --env-file .env exec db pg_dump -U alwakeel construction > backup.sql

احتفظ بملف backup.sql في مكان آمن. البيانات الحالية فعليًا
محفوظة داخل وحدة تخزين Docker باسم db-data.


--------------------------
استكشاف الأخطاء السريع
--------------------------
• "Docker is not installed / not running":
    شغّل Docker Desktop وانتظر حتى تصبح جاهزة، ثم أعد التشغيل.

• الرابط لا يفتح:
    تأكد أن Tailscale متصل (الأيقونة خضراء) وأنك مسجّل بالشبكة.

• لمظالعة سجل البرنامج:
    docker compose --env-file .env logs app


------------------
ملاحظات أمنية
------------------
• ملف ".env" يحتوي بيانات الدخول — لا تشاركه مع أحد.
• صورة البرنامج عامة لكنها لا تحتوي على أي من بياناتك.
